HOME PAGE (/)
├─ View hero carousel & amenities
├─ Browse featured rooms
├─ Browse Events/Experiences
├─ Browse testimonials
└──→ Search: Pick check-in/checkout dates → REDIRECTS TO PROPERTY PAGE
                                                      ↓
PROPERTY PAGE (/property)
├─ View detailed room catalog
├─ See live availability & pricing per room type
├─ View amenities, guidelines, FAQs
├─ Filter/compare room options
└──→ SELECT ROOM(s) + quantity → ADD TO BOOKING → CHECKOUT PAGE
                                                      ↓
BOOKING CHECKOUT PAGE (/booking)
│   ┌─────────────────────────────────────┐
│   │ TAB 1: GUEST DETAILS                 │
│   ├─ Enter first name, last name        │
│   ├─ Enter email, phone                 │
│   ├─ Confirm guest count & ages         │
│   └─→ CONTINUE TO ADD-ONS                │
│                                         │
│   ├──→ TAB 2: ADD-ONS (Optional)        │
│   │   ├─ Browse store items (meals,    │
│   │   │   laundry, workspace, etc.)    │
│   │   ├─ Add/remove quantities         │
│   │   └─→ PROCEED TO PAYMENT            │
│   │                                    │
│   └──→ TAB 3: PAYMENT                   │
│       ├─ View booking summary          │
│       │  (dates, room, guests, total)  │
│       ├─ View final price breakdown    │
│       └─→ CONTINUE TO PAYMENT          │
│                    ↓
├─ (IF NOT SIGNED IN) → SIGN-IN MODAL (Google OAuth or email/password)
│                    ↓
└──→ Razorpay Payment Gateway Opens
        │ Guest pays via card/UPI/wallet
        │
        ├─→ ✓ PAYMENT SUCCESSFUL → ORDER CONFIRMED
        │          ↓
        │    (Booking reservation created)
        │          ↓
        └──→ REDIRECTS TO MY BOOKINGS PAGE (/bookings?fresh=<eri>)
                          ↓
MY BOOKINGS PAGE (/bookings)
├─ View all bookings organized in tabs:
│  ├─ UPCOMING (future bookings)
│  ├─ ACTIVE (current stay)
│  └─ PAST (completed/cancelled)
├─ Each booking card shows:
│  ├─ Dates, room type, guest count
│  ├─ Booking status
│  └─ CTUA: "View" or "Web Check-in"
├─ Filter by date range
├─ Refresh booking list
└──→ CLICK BOOKING CARD → BOOKING DETAILS
                          or
                     → WEB CHECK-IN
                              ↓
WEB CHECK-IN PAGE (/bookings/[eri]/web-check-in)
│   Status check: If payment still pending
│   └──→ SHOW "Complete payment first" message
│   
│   If payment done, proceed to KYC:
│   ┌─────────────────────────────────────┐
│   │ STEP 1: BASIC INFO                   │
│   ├─ Full name (prefilled)              │
│   ├─ Date of birth                      │
│   ├─ Nationality                        │
│   ├─ Current location                   │
│   ├─ Gender                             │
│   ├─ Email & phone (prefilled)          │
│   └─→ NEXT STEP                          │
│                                         │
│   ├──→ STEP 2: ID VERIFICATION          │
│   │   ├─ Select ID type:                │
│   │   │  (Aadhaar / Passport /          │
│   │   │   Voter ID / Driving License)   │
│   │   ├─ Enter ID number (auto-detects  │
│   │   │   from pattern as you type)     │
│   │   ├─ Upload ID front + back photos  │
│   │   ├─ Crop tool for image alignment  │
│   │   ├─ Run OCR scan                   │
│   │   ├─ Accept consent checkboxes      │
│   │   └─→ NEXT STEP                      │
│   │                                    │
│   └──→ STEP 3: TIME SLOT SELECTION      │
│       ├─ View available check-in slots  │
│       ├─ Select preferred time          │
│       ├─ Confirm final details          │
│       └─→ SUBMIT (KYC Complete)         │
│              ↓
│      (OCR + ID validation on backend)
│              ↓
└──→ CONFIRMED PAGE (/bookings/[eri]/confirmed)
        ├─ ✓ Check-in VERIFIED
        ├─ Display booking summary
        ├─ Show check-in time slot
        ├─ Link to guidelines & policies
        ├─ Contact info for support
        └─ Ready for check-in day!

COLIVE FLOW (Separate flow for monthly rentals)

│
├─→ CHECKOUT STEP 1: Guest Details

│   └─→ NEXT
│

│   ├─ Pick move-in date
│   ├─ Select duration (months)
│   ├─ Add optional services
│   │  (meals, laundry, workspace)
│   └─→ REVIEW BOOKING
│
├─→ CHECKOUT STEP 3: Review & Payment
│   ├─ Verify all details locked
│   ├─ See final price
│   └─→ PAY AND CONFIRM
│
├─ Razorpay Payment
│
└─→ CONFIRMATION → Access booking details

Page	User Can...
Home	Search dates, browse rooms, explore amenities, view events
Property	Filter rooms, check availability, add to booking, compare prices
Booking	Enter guest info, select add-ons, review & pay, use Razorpay
My Bookings	View all bookings, filter by status, access check-in, track dates
Web Check-in	Complete KYC, upload ID, verify details, select time slot
Confirmed	View check-in confirmation, access guidelines, contact support
Colive	Compare long-stay options, book monthly, add monthly services



Main Flow: Home → Property → Booking Checkout (Guest Details → Add-ons → Payment) → My Bookings → Web Check-in (KYC Steps 1-3) → Confirmed

Alternate Flow: Colive landing page for long-stay bookings with its own 3-step checkout process
