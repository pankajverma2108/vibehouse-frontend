# Vibehouse Modern Dark Design System & Experience Redesign

## Overview
This folder contains the complete, rigorous architectural blueprint and multi-phased roadmap for overhauling the visual language, design system, typography, and homepage experience for **Vibehouse / The Daily Social**.

## Motivation & Objectives
1. **Pitch-Black True Dark Theme**: Transition from inconsistent/muddy charcoal backgrounds (`#07070a`, `#0a0a0e`, `#0d0d0d`) to a deep, pitch-black luxury dark foundation (`#000000` / `#050505`), utilizing high-contrast crisp surfaces (`#0c0c0e`, `#121215`, `#18181c`).
2. **Retire Cluttered/Ugly Hero Animations**: Completely remove the CPU-heavy, distracting Three.js particle canvas (`AmbientCanvas`) and dizzying 6-second zoom carousel. Replace with a clean, high-conversion, architecturally stunning hero anchored by an intuitive booking engine and clear trust signals.
3. **Design System Modernization**: Sunset the clunky, cartoonish NeoBrutalism (thick 6px solid borders, hard 0px drop shadows, mismatched neons). Introduce a sleek, "tool-native" product aesthetic inspired by [Nudge Folio](https://nudge-folio.framer.website/) and modern design platforms (Linear, Framer, Figma).
4. **Benchmark Hospitality Best Practices**: Synthesize UX and conversion patterns from India's benchmark modern hospitality brands: **Bloom Hotels**, **Zostel**, **GoStops**, and **TheHosteller**.
5. **Nudge Folio Color & Typography Alignment**: Adopt the vibrant quad-color accent palette (Electric Cyan, Warm Amber, Emerald Mint, Vivid Crimson) and typography hierarchy (`Inter Display`, `Inter`, `DM Mono`, `Geist Mono`).
6. **Zero Regression / 100% Working Project**: Maintain complete functional compatibility with existing dynamic routes, booking flows, query parameters (`checkin`, `checkout`, `property_id`), and guest authentication states.
