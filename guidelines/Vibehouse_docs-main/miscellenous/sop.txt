Partner Dashboard 
Adding users and building 
from Partner Admin Role 
(Vendor side) 
Login
●Login with registered Partner Admin Role mobile number and OTP 
●Make sure you get your number registered as Partner Admin from Mygate 
Tech Team 

Add New Building 
●Click on the “ Add 
Building ” Button. 
●Add building details. 
●Click on the view button to 
start adding more details 
for building like rooms and 
connect locks to rooms 

Add Building Details 
●Add the building manager . 
Select from the list or add new 
from “Manager” section 
●Click on “ Add room ” to keep 
adding new rooms. 
●After adding the rooms, click on 
the “Connect Lock ” button to 
attach the Serial number of the 
lock installed on the door of the 
room. 
You can find the serial numbers 
pasted inside lock battery panel. 
●Make sure that 
the lock is already 
setup and is 
present in the 
system before 
you start mapping 
it to the room. 

How to Setup Lock from App 
●Install “ Mygate Smart Devices ” app and register with user who will be having the Super Admin Role  on 
all the locks configured by that mobile number. 
●Click on “+ Add” button, then select “Smart Lock” and follow the steps shown on the screen to setup your 
lock.
●Ensure that you are near the lock while performing this action and lock is installed and has battery put in. 

Partner Dashboard 
Create and Manage PINs 
(Vendor side) 
Add New PIN Access 
●Click on the “ Properties ” 
from the side bar. 
●Select the tab “ Manage 
PINs ”
●OR Select “ Manage PINs ” 
from the Side bar. 
●Click on “ Create New 
PIN”.

Add New PIN Access 
●Enter PIN Label i.e identifier for the 
access. 
●Select the user you are creating the 
access for. 
●Choose the property and room for 
which access is being created. 
●Select the PIN type. (Note for Custom 
PIN, your lock should be connected to 
Gateway). 
●Select the Validity period and then 
click on Create PIN to generate the 
access. 
●Please note that One-time validity is not 
available for custom PIN. 

Partner Dashboard 
Create and Manage App 
Access 
(Vendor side) 
Add New App Access 
●Click on the “ Manage 
Access ” from the side bar. 
●Select the tab “ App 
Access ” to view the list of 
App accesses created. 
●Click on “ Create New 
Access ”, Select “ App 
Access ”

Add New App Access 
●Enter App Label i.e identifier for the 
access. 
●Select the user you are creating the 
access for. 
●Choose the property and room for 
which access is being created. 
●Select the Validity period. 
●By-default the make-authorised 
admin toggle is turn ON, i.e. when 
you create the app access user will 
get the admin access for the lock. 
●If you wish not to provide admin 
access, turn OFF the toggle.
